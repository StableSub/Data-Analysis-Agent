# Moldset Quantitative Metrics

## 목적

이 문서는 `evaluation/raw/moldset_labeled.csv`를 기준으로 실제 분석 결과와 AI 응답 결과를 비교하기 위한 정량 평가 항목을 정리한다.

정량 지표의 목적은 AI가 자연어 질문에 대해 데이터 필터링, 그룹화, 비율 계산, 날짜 버킷팅, 데이터 품질 profiling을 실제 계산값과 동일하게 수행하는지 확인하는 것이다.

## 평가 기준

- 실제 분석 결과는 `evaluation/raw/moldset_labeled.csv`를 pandas로 계산한 oracle 값이다.
- AI 응답 결과는 동일 질문을 Workbench 또는 benchmark runner로 실행한 뒤 기록한다.
- 건수와 범주 coverage는 exact match를 기준으로 한다.
- 비율은 소수점 반올림 차이를 고려해 ±0.01%p 이내를 허용한다.
- 날짜별 집계는 `TimeStamp` 컬럼을 날짜 단위로 변환한 값을 기준으로 한다.
- 불량 관련 집계는 명시적으로 `PassOrFail=1` 필터를 적용한다.
- benchmark case manifest는 `evaluation/cases/`의 JSONL 파일에 둔다. 현재 기본 세트는 P0 moldset analysis/preprocess와 P1 unanswerable/scaled dataset 품질 케이스를 포함한다.

## 판정 방식

| 항목 | 통과 기준 |
|---|---|
| Count exact match | 실제 건수와 AI 응답 건수가 동일해야 한다. |
| Category coverage | 실제 범주가 모두 포함되고, 존재하지 않는 범주가 추가되지 않아야 한다. |
| Rate tolerance | 실제 비율과 AI 응답 비율의 차이가 ±0.01%p 이내여야 한다. |
| Filter correctness | `PassOrFail=1` 조건이 필요한 질문에서 정상 데이터가 섞이지 않아야 한다. |
| Date bucket correctness | `TimeStamp` 기준 날짜 버킷이 실제 결과와 일치해야 한다. |
| Data-quality precision | 전부 0인 컬럼만 포함해야 한다. |

## 발표용 해석 문장

위 5개 정량 지표는 라벨 집계, 제품별 비율 계산, 조건부 범주 집계, 날짜 단위 집계, 데이터 품질 profiling을 각각 검증한다. AI 응답 결과가 실제 pandas 계산값과 일치하면, 이 시스템이 단순 요약이 아니라 데이터 분석에 필요한 핵심 연산을 정확히 수행할 수 있음을 근거로 제시할 수 있다.

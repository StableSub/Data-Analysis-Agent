# Moldset 질문 문서

## 목적

이 문서는 `evaluation/raw/moldset_labeled.csv`를 대표 데이터셋으로 사용할 때의 질문 문서 묶음을 안내한다.

기존에는 데이터 이해, 전처리, 분석, 시각화, 레포트 질문을 한 파일에 모았지만, 현재는 `moldset-*-questions.md` 형식의 섹션별 문서로 분리한다.

## 섹션별 문서

| 섹션 | 문서 | 용도 |
|---|---|---|
| 시나리오 | `evaluation/docs/moldset-quality-priority-scenario.md` | 분석/전처리, 시각화, 레포트 질문을 하나의 품질관리 흐름으로 연결 |
| 분석/전처리 | `evaluation/docs/moldset-analysis-questions.md` | 데이터 이해, 전처리 확인, 분석 실행, 근거/한계 확인 |
| 시각화 | `evaluation/docs/moldset-visualization-questions.md` | 단일 차트 생성 질문과 시각화 평가 기준 |
| 레포트 | `evaluation/docs/moldset-report-questions.md` | 품질 현황/원인 후보/개선 제안 리포트 질문 |

## 판단 요약

현재 Moldset 시나리오는 프로젝트 평가용으로 적절하다. 데이터 이해, 전처리 approval, 분석, 시각화, 리포트, 한계 확인까지 Workbench의 주요 흐름을 한 데이터셋에서 순서대로 확인할 수 있기 때문이다.

수정이 필요한 부분은 질문 범위가 넓거나 필터가 생략되어 응답이 흔들릴 수 있는 표현이다. 특히 불량 사유 집계는 정상 행의 `Reason=None`을 섞지 않도록 `PassOrFail=1` 조건을 질문에 직접 포함해야 한다.

## 기본 노출 추천 5개

1. 이 데이터셋의 행 수, 컬럼 수, 주요 컬럼을 요약해줘.
2. 이 데이터에서 분석 전에 전처리가 필요한 부분을 찾아줘.
3. 제품별 불량률을 계산해줘.
4. PassOrFail 라벨별 건수를 막대그래프로 시각화해줘.
5. 이 데이터의 전체 품질 현황을 요약하는 리포트를 작성해줘. 양품/불량 비율, 불량 사유, 제품별 생산량을 포함해줘.

## 질문 명확성 판단 기준

- 불량 사유별 건수는 `PassOrFail=1인 불량 데이터만 대상으로 불량 사유별 건수를 알려줘.`처럼 필터를 명시한다.
- 제품별 불량률은 제품별 총 생산량을 분모로 쓰는 비율 계산임을 기대 결과에 함께 둔다.
- 전처리 질문은 `_id`, `Unnamed: 0`, `PART_FACT_SERIAL`, `PART_NO`, `PART_NAME`, `TimeStamp`, `PassOrFail` 같은 보호/식별 컬럼을 변환 대상에서 제외해야 한다.
- 시각화 질문은 한 질문당 단일 `chart_data` 또는 `charts[0]`로 검증 가능한 차트 하나만 요구한다.
- 리포트 질문은 여러 분석 결과를 요약할 수 있지만, 별도 분석 실행과 여러 차트 생성을 동시에 요구하지 않는다.
- 원인 관련 질문은 원인을 확정하지 않고 관련 가능성, 한계, 추가로 필요한 데이터를 구분하도록 작성한다.

## 문서 사용 기준

- UI 추천 질문을 구성할 때는 섹션별 파일을 우선 참고한다.
- benchmark/evaluation에서 세부 oracle이 필요하면 각 섹션 문서의 기대 결과와 체크리스트를 함께 본다.
- 질문은 실제 존재하는 컬럼만 사용한다.
- 한 질문에서 분석, 여러 차트, 레포트를 동시에 요구하지 않는다.
- 시각화 질문은 현재 구현 기준에서 단일 `chart_data` 또는 `charts[0]`로 검증 가능한 질문을 우선한다.

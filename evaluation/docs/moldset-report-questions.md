# Moldset 레포트 테스트 질문

## 목적

이 문서는 `evaluation/raw/moldset_labeled.csv` 데이터셋으로 데이터 분석 AI 에이전트의 리포트 작성 품질을 확인하기 위한 질문 모음이다.

레포트 평가의 핵심은 단순한 요약이 아니라, 데이터 개요·품질 현황·불량 원인 후보·제품별 차이·시간 흐름·데이터 품질 이슈·실무 개선 제안을 구조적으로 정리하는지 확인하는 것이다.

## 데이터 확인 기준

- 전체 행 수: 2,607건
- 정상: 2,555건
- 불량: 52건
- 불량률: 약 2.0%
- 주요 불량 사유:
  - 가스: 30건
  - 미성형: 12건
  - 초기허용불량: 10건
- 제품: 4종
  - `CN7 W/S SIDE MLD'G RH`
  - `CN7 W/S SIDE MLD'G LH`
  - `RG3 MOLD'G W/SHLD, LH`
  - `RG3 MOLD'G W/SHLD, RH`
- 설비: `650톤-우진2호기` 단일 설비
- 주의할 데이터 품질 이슈:
  - 일부 온도 컬럼은 전부 0이다.
  - 일부 위치 컬럼은 대부분 0이다.
  - `_id`, `row_index` 등 식별자 컬럼은 분석 변수에서 제외해야 한다.

## 추천 레포트 질문

### 1. 기본 품질 현황 리포트

```text
이 데이터의 전체 품질 현황을 요약하는 리포트를 작성해줘. 양품/불량 비율, 불량 사유, 제품별 생산량을 포함해줘.
```

좋은 레포트 기준:

- 전체 2,607건 기준으로 데이터 규모를 설명한다.
- 불량 52건, 약 2% 수준이라는 핵심 수치를 제시한다.
- 불량 사유 중 `가스`가 가장 많다는 점을 요약한다.
- 제품 4종과 단일 설비 구조를 설명한다.
- 단순 요약에 그치지 않고 품질 관리 관점의 시사점을 제시한다.

### 2. 불량 원인 후보 리포트

```text
양품과 불량의 주요 수치형 공정 변수 차이를 비교해서, 불량과 관련 가능성이 높은 변수 후보를 리포트로 정리해줘. 보호/식별 컬럼과 전부 0인 컬럼은 비교 대상에서 제외해줘.
```

좋은 레포트 기준:

- 원인을 단정하지 않고 “관련 가능성이 높은 변수”로 표현한다.
- 압력 계열 변수를 우선적으로 검토한다.
  - `Average_Back_Pressure`
  - `Max_Back_Pressure`
  - `Max_Injection_Pressure`
- 온도/시간 계열 변수도 보조적으로 비교한다.
- 불량 표본 수가 52건으로 작다는 한계를 포함한다.
- 추가 검증이 필요한 항목을 구분한다.

### 3. 제품별 품질 비교 리포트

```text
제품별 불량률을 비교하고, 어떤 제품에서 품질 리스크가 상대적으로 큰지 리포트로 작성해줘.
```

좋은 레포트 기준:

- 제품별 불량 건수만 보지 않고 불량률을 계산한다.
- 제품별 총 생산량 차이를 고려한다.
- LH/RH 차이 또는 CN7/RG3 차이를 구분해서 설명한다.
- 표본 수가 작은 경우 과도한 해석을 피한다.
- 제품별 관리 우선순위를 제안한다.

### 4. 불량 사유별 분석 리포트

```text
PassOrFail=1인 불량 데이터를 대상으로 Reason별 표본 수를 먼저 확인하고, 불량 사유별 주요 수치형 공정 조건 차이를 리포트로 정리해줘.
```

좋은 레포트 기준:

- `가스`, `미성형`, `초기허용불량`을 분리해서 분석한다.
- 각 사유별 표본 수를 먼저 제시한다.
- 사유별 공정 변수 차이를 비교한다.
- 사유별 개선 점검 항목을 제안한다.
- 사유별 표본 수가 작다는 한계를 명시한다.

### 5. 시간대별 품질 리포트

```text
시간 흐름에 따른 불량 발생 패턴을 분석하고, 특정 날짜나 시간대에 불량이 집중되는지 리포트로 작성해줘.
```

좋은 레포트 기준:

- `TimeStamp` 기반으로 분석한다.
- 날짜별 또는 시간대별 생산량과 불량률을 비교한다.
- 특정 시점에 불량이 몰리는지 설명한다.
- 제품 전환이나 공정 조건 변화 가능성을 함께 언급한다.
- 생산량이 적은 시간 구간의 불량률을 과도하게 해석하지 않는다.

### 6. 데이터 품질 진단 리포트

```text
이 데이터의 분석 가능성을 평가하는 데이터 품질 리포트를 작성해줘. 결측, 0값, 상수 컬럼, 제외해야 할 컬럼을 포함해줘.
```

좋은 레포트 기준:

- `_id`, `row_index` 같은 식별자 컬럼을 분석 변수에서 제외한다.
- 전부 0인 컬럼을 식별한다.
- 대부분 0인 컬럼을 식별한다.
- `Mold_Temperature` 다수 컬럼이 분석에 부적합하다는 점을 언급한다.
- 실제 분석에 쓸 수 있는 컬럼과 제외할 컬럼을 구분한다.
- 데이터 품질 이슈가 분석 결과 신뢰도에 미치는 영향을 설명한다.

### 7. 공정 안정성 리포트

```text
Injection_Time, Cycle_Time, Max_Injection_Pressure, Max_Back_Pressure 등 주요 수치형 공정 변수의 안정성을 평가하고, 변동성이 큰 항목과 관리가 필요한 항목을 리포트로 정리해줘. 보호/식별 컬럼은 제외해줘.
```

좋은 레포트 기준:

- 평균, 중앙값, 범위, 이상치 등 기본 통계 기준을 설명한다.
- 시간, 압력, 온도 변수의 변동성을 비교한다.
- 불량 발생 시 변수 변동이 커지는지 확인한다.
- 관리 우선순위를 제안한다.
- 정상 공정 범위와 이상 구간을 구분해서 설명한다.

### 8. 품질 개선 제안 리포트

```text
분석 결과를 바탕으로 사출 성형 품질 개선을 위한 실무적 점검 항목과 우선순위를 제안하는 리포트를 작성해줘.
```

좋은 레포트 기준:

- 불량 유형별 점검 항목을 제안한다.
- 압력 조건 점검 필요성을 설명한다.
- 온도 센서 데이터 품질 점검 필요성을 설명한다.
- 제품별 관리 기준 검토를 제안한다.
- 추가로 수집하면 좋은 데이터를 제안한다.
- 과도한 원인 단정 없이 개선 방향을 제시한다.

### 9. 종합 분석 리포트

```text
이 데이터에 대한 종합 품질 분석 리포트를 작성해줘. 데이터 개요, 불량 현황, 제품별 품질, 공정 변수 분석, 시간 추세, 데이터 품질 이슈, 개선 제안을 포함해줘.
```

좋은 레포트 기준:

- 섹션 구조가 명확하다.
- 숫자 기반 요약이 포함된다.
- 시각화 결과를 설명하는 문장이 있다.
- 한계와 후속 분석 방향이 있다.
- 실무자가 읽을 수 있는 결론이 있다.
- 분석 결과와 개선 제안이 연결되어 있다.

### 10. 경영진용 요약 리포트

```text
이 데이터 분석 결과를 비전문가도 이해할 수 있도록 경영진용 요약 리포트로 작성해줘.
```

좋은 레포트 기준:

- 기술 변수 설명이 과도하게 길지 않다.
- 핵심 숫자 중심으로 요약한다.
- 불량률, 주요 불량 사유, 관리 우선순위를 제시한다.
- “현재 데이터만으로 원인을 확정할 수 없다”는 한계를 포함한다.
- 다음 액션이 명확하다.

## 우선 테스트 질문 TOP 3

### TOP 1

```text
이 데이터의 전체 품질 현황을 요약하는 리포트를 작성해줘. 양품/불량 비율, 불량 사유, 제품별 생산량을 포함해줘.
```

이 질문은 데이터 개요, 기본 품질 지표, 범주형 요약, 실무 해석 능력을 확인하기 좋다.

### TOP 2

```text
양품과 불량의 주요 수치형 공정 변수 차이를 비교해서, 불량과 관련 가능성이 높은 변수 후보를 리포트로 정리해줘. 보호/식별 컬럼과 전부 0인 컬럼은 비교 대상에서 제외해줘.
```

이 질문은 수치형 변수 비교, 불량 관련 변수 후보 도출, 원인 단정 방지 능력을 확인하기 좋다.

### TOP 3

```text
이 데이터에 대한 종합 품질 분석 리포트를 작성해줘. 데이터 개요, 불량 현황, 제품별 품질, 공정 변수 분석, 시간 추세, 데이터 품질 이슈, 개선 제안을 포함해줘.
```

이 질문은 레포트 구조화, 분석 흐름 구성, 한계 인식, 개선 제안까지 종합적으로 확인하기 좋다.

## 레포트 결과 평가 체크리스트

- [ ] 전체 데이터 규모와 불량률을 정확히 제시한다.
- [ ] 불량 사유별 건수와 비율을 구분해서 설명한다.
- [ ] 제품별 비교에서 총 생산량과 불량률을 함께 고려한다.
- [ ] 양품/불량 공정 변수 차이를 숫자와 해석으로 연결한다.
- [ ] 식별자 컬럼을 분석 변수로 사용하지 않는다.
- [ ] 전부 0이거나 대부분 0인 컬럼을 데이터 품질 이슈로 지적한다.
- [ ] 불량 표본 수가 적다는 한계를 명시한다.
- [ ] 원인을 단정하지 않고 관련 가능성으로 표현한다.
- [ ] 실무적인 점검 항목 또는 개선 제안을 포함한다.
- [ ] 경영진용/실무자용 등 요청한 독자 수준에 맞게 설명한다.

# Moldset 시각화 테스트 질문

## 목적

이 문서는 `evaluation/raw/moldset_labeled.csv` 데이터셋으로 데이터 분석 AI 에이전트의 시각화 생성 품질을 확인하기 위한 질문 모음이다.

시각화 평가의 핵심은 단순히 그래프를 많이 만드는 것이 아니라, 데이터의 품질 관리 문제를 드러낼 수 있는 적절한 차트 유형을 선택하고, 불량률·제품별 차이·공정 변수 분포·시간 흐름·데이터 품질 이슈를 시각적으로 확인할 수 있게 만드는 것이다.

## 데이터 확인 기준

- 전체 행 수: 2,607건
- 정상: 2,555건
- 불량: 52건
- 불량률: 약 2.0%
- 주요 불량 사유:
  - 가스: 30건
  - 미성형: 12건
  - 초기허용불량: 10건
- 제품: 4종
  - `CN7 W/S SIDE MLD'G RH`
  - `CN7 W/S SIDE MLD'G LH`
  - `RG3 MOLD'G W/SHLD, LH`
  - `RG3 MOLD'G W/SHLD, RH`
- 설비: `650톤-우진2호기` 단일 설비
- 주의할 데이터 품질 이슈:
  - 일부 온도 컬럼은 전부 0이다.
  - 일부 위치 컬럼은 대부분 0이다.
  - `_id`, `row_index` 등 식별자 컬럼은 분석 변수에서 제외해야 한다.

## 추천 시각화 질문

현재 구현 단계에서는 한 질문이 하나의 시각화 결과만 요구하도록 구성한다. 즉, 각 질문의 기대 결과는 단일 `chart_data` 또는 `charts[0]`이며, 한 질문에서 여러 그래프를 동시에 요구하지 않는다.

### 1. 라벨 분포 막대그래프

```text
PassOrFail 라벨별 건수를 막대그래프로 시각화해줘.
```

기대 결과:

- 차트 1개
- 차트 유형: bar
- x축: `PassOrFail`
- y축: count 계열
- 기대값:
  - `0`: 2,555건
  - `1`: 52건

확인 포인트:

- 정상/불량 불균형이 막대 높이로 드러나는가
- `PassOrFail` 외 불필요한 컬럼을 섞지 않는가
- 다른 차트를 추가로 생성하지 않는가

### 2. 불량 사유별 건수 막대그래프

```text
PassOrFail=1인 불량 데이터만 대상으로 Reason별 건수를 막대그래프로 시각화해줘.
```

기대 결과:

- 차트 1개
- 차트 유형: bar
- x축: `Reason`
- y축: defect_count 또는 count 계열
- 기대값:
  - `가스`: 30건
  - `미성형`: 12건
  - `초기허용불량`: 10건

확인 포인트:

- `PassOrFail=1`인 행만 대상으로 집계하는가
- 정상 데이터의 `Reason=None` 또는 NaN을 불량 사유로 취급하지 않는가
- 건수와 비율을 동시에 요구하지 않고 사유별 건수 하나만 시각화하는가

### 3. 제품별 불량률 막대그래프

```text
제품별 불량률을 막대그래프로 시각화해줘.
```

기대 결과:

- 차트 1개
- 차트 유형: bar
- x축: `PART_NAME`
- y축: `defect_rate_pct` 또는 동등한 불량률 값
- 기대값:
  - `CN7 W/S SIDE MLD'G LH`: 약 1.26%
  - `CN7 W/S SIDE MLD'G RH`: 약 2.52%
  - `RG3 MOLD'G W/SHLD, LH`: 0.00%
  - `RG3 MOLD'G W/SHLD, RH`: 약 4.23%

확인 포인트:

- 단순 불량 건수가 아니라 제품별 불량률을 계산하는가
- 4개 제품이 모두 표시되는가
- 제품별 총 생산량과 불량률을 한 차트에 복합으로 억지 표시하지 않는가

### 4. 제품별 총 생산량 막대그래프

```text
제품별 총 생산량을 막대그래프로 시각화해줘.
```

기대 결과:

- 차트 1개
- 차트 유형: bar
- x축: `PART_NAME`
- y축: total_count 또는 count 계열
- 기대값:
  - `CN7 W/S SIDE MLD'G LH`: 712건
  - `CN7 W/S SIDE MLD'G RH`: 713건
  - `RG3 MOLD'G W/SHLD, LH`: 591건
  - `RG3 MOLD'G W/SHLD, RH`: 591건

확인 포인트:

- 제품별 표본 수 차이를 볼 수 있는가
- 불량률까지 같이 그리라고 확장하지 않는가
- 제품명 축이 해석 가능한 형태로 표시되는가

### 5. 날짜별 불량 건수 라인 차트

```text
날짜별 불량 건수 추이를 라인 차트로 시각화해줘.
```

기대 결과:

- 차트 1개
- 차트 유형: line
- x축: `TimeStamp` 기반 날짜 버킷
- y축: defect_count 또는 count 계열
- 기대값:
  - `2020-10-16`: 17건
  - `2020-10-22`: 15건
  - `2020-10-23`: 10건
  - `2020-10-27`: 10건

확인 포인트:

- `TimeStamp`를 날짜 단위로 묶는가
- `PassOrFail=1`만 불량 건수로 집계하는가
- 생산량, 불량률, 불량 발생 시점 표시를 함께 넣은 복합 차트로 확장하지 않는가

### 6. 두 공정 변수 관계 산점도

```text
Max_Injection_Pressure와 Cycle_Time의 관계를 산점도로 시각화해줘. 집계하지 말고 각 행을 점으로 표시해줘.
```

기대 결과:

- 차트 1개
- 차트 유형: scatter
- x축: `Max_Injection_Pressure`
- y축: `Cycle_Time`
- 각 행이 하나의 점으로 표시됨

확인 포인트:

- 평균 또는 그룹 집계 없이 행 단위 점으로 표시하는가
- 두 수치형 컬럼만 사용해 관계를 보여주는가
- 상관계수, 회귀선, 이상치 분석까지 과하게 확장하지 않는가

## 우선 테스트 질문 TOP 3

### TOP 1

```text
PassOrFail 라벨별 건수를 막대그래프로 시각화해줘.
```

이 질문은 단일 범주형 집계 차트로 `PassOrFail`의 정상/불량 불균형을 가장 단순하게 확인할 수 있다.

### TOP 2

```text
PassOrFail=1인 불량 데이터만 대상으로 Reason별 건수를 막대그래프로 시각화해줘.
```

이 질문은 불량 행 필터링, `Reason` 범주형 집계, 정상 데이터의 `Reason=None` 제외 여부를 확인하기 좋다.

### TOP 3

```text
제품별 불량률을 막대그래프로 시각화해줘.
```

이 질문은 제품별 group-by, 불량률 계산, 제품 4종 표시 여부를 단일 막대그래프로 검증하기 좋다.

## 현재 단계에서 제외하는 시각화 질문

아래 질문 유형은 제품적으로 유용하지만, 현재 evaluation에서는 한 질문당 단일 시각화 결과를 안정적으로 검증하기 어렵거나 구현 단계보다 요구가 크므로 후순위로 둔다.

- 한 질문에서 여러 그래프를 동시에 요구하는 질문
- 양품/불량별 여러 공정 변수 분포를 한 번에 비교하는 질문
- 히트맵 기반 상관관계 시각화
- 박스플롯, 바이올린 플롯 등 broad distribution 비교
- 결측값, 0값 비율, 상수 컬럼을 한 번에 보여주는 데이터 품질 종합 시각화
- 생산량, 불량 건수, 불량률을 한 차트에 함께 표시하는 복합 차트

## 시각화 결과 평가 체크리스트

- [ ] 질문 하나가 시각화 결과 하나만 요구한다.
- [ ] 반환 결과의 `chart_data` 또는 `charts[0]`가 질문 목적과 일치한다.
- [ ] 질문 목적에 맞는 차트 유형을 선택한다: bar, line, scatter 중 하나.
- [ ] x축과 y축이 기대 컬럼 또는 기대 metric alias와 일치한다.
- [ ] 기대 count/rate oracle과 시각화 값이 일치한다.
- [ ] `PassOrFail=1` 필터가 필요한 질문에서 정상 데이터를 섞지 않는다.
- [ ] 제품별 비교에서 4개 제품이 모두 표시된다.
- [ ] 산점도 질문에서 집계하지 않고 행 단위 점을 사용한다.
- [ ] 그래프가 너무 복잡하지 않고 해석 가능한 수준으로 구성된다.
- [ ] 시각화 해석에서 원인을 단정하지 않고 관련 가능성으로 표현한다.

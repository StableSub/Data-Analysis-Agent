# Moldset 시각화 테스트 질문

## 목적

이 문서는 `evaluation/raw/moldset_labeled.csv` 데이터셋으로 데이터 분석 AI 에이전트의 시각화 생성 품질을 확인하기 위한 질문 모음이다.

시각화 평가의 핵심은 단순히 그래프를 많이 만드는 것이 아니라, 데이터의 품질 관리 문제를 드러낼 수 있는 적절한 차트 유형을 선택하고, 불량률·제품별 차이·공정 변수 분포·시간 흐름·데이터 품질 이슈를 시각적으로 확인할 수 있게 만드는 것이다.

## 데이터 확인 기준

- 전체 행 수: 2,607건
- 정상: 2,555건
- 불량: 52건
- 불량률: 약 2.0%
- 주요 불량 사유:
  - 가스: 30건
  - 미성형: 12건
  - 초기허용불량: 10건
- 제품: 4종
  - `CN7 W/S SIDE MLD'G RH`
  - `CN7 W/S SIDE MLD'G LH`
  - `RG3 MOLD'G W/SHLD, LH`
  - `RG3 MOLD'G W/SHLD, RH`
- 설비: `650톤-우진2호기` 단일 설비
- 주의할 데이터 품질 이슈:
  - 일부 온도 컬럼은 전부 0이다.
  - 일부 위치 컬럼은 대부분 0이다.
  - `_id`, `row_index` 등 식별자 컬럼은 분석 변수에서 제외해야 한다.

## 추천 시각화 질문

### 1. 기본 분포 시각화

```text
양품과 불량의 비율, 불량 사유별 건수, 제품별 생산량을 각각 적절한 그래프로 시각화해줘.
```

확인 포인트:

- `PassOrFail` 비율 차트를 생성하는가
- `Reason`별 막대그래프를 생성하는가
- `PART_NAME` 또는 `PART_NO`별 생산량 막대그래프를 생성하는가
- 불량이 전체 대비 매우 적다는 점이 시각적으로 드러나는가
- 불량 사유가 정상 데이터의 `None`과 섞이지 않도록 처리하는가

### 2. 제품별 불량률 시각화

```text
제품별 총 생산 수와 불량률을 비교할 수 있도록 시각화해줘.
```

확인 포인트:

- 단순 불량 건수가 아니라 불량률을 계산하는가
- 제품별 총 생산 수와 불량률을 함께 보여주는가
- 제품별 표본 수 차이를 고려하는가
- 막대그래프 또는 복합 차트를 적절히 선택하는가
- LH/RH, CN7/RG3 차이를 구분해서 볼 수 있는가

### 3. 불량 사유별 분포 시각화

```text
불량 사유별 발생 빈도를 시각화하고, 각 사유가 전체 불량에서 차지하는 비율을 보여줘.
```

확인 포인트:

- `가스`, `미성형`, `초기허용불량`을 분리해서 보여주는가
- 전체 데이터 기준 비율과 불량 데이터 내부 비율을 혼동하지 않는가
- 불량 사유별 건수와 비율을 함께 보여주는가
- 정상 데이터의 `Reason=None`을 불량 사유로 취급하지 않는가

### 4. 양품/불량별 공정 변수 분포 시각화

```text
양품과 불량을 기준으로 주요 공정 변수의 분포를 비교 시각화해줘.
```

추천 변수:

- `Average_Back_Pressure`
- `Max_Back_Pressure`
- `Max_Injection_Pressure`
- `Hopper_Temperature`
- `Cycle_Time`
- `Filling_Time`

확인 포인트:

- boxplot, violin plot, histogram 등을 적절히 사용하는가
- 양품과 불량의 분포 차이가 보이는가
- 불량 표본 수가 52건으로 적다는 점을 시각화 해석에 반영하는가
- 여러 변수를 한 그래프에 과도하게 넣어 해석이 어려워지지 않는가

### 5. 시간 흐름 시각화

```text
시간 흐름에 따라 생산량과 불량 발생 추이를 시각화해줘.
```

확인 포인트:

- `TimeStamp`를 시간 컬럼으로 인식하는가
- 날짜별 또는 시간대별 생산량을 집계하는가
- 날짜별 또는 시간대별 불량 건수와 불량률을 함께 보여주는가
- 불량 발생 시점이 시각적으로 표시되는가
- 생산량이 적은 구간의 불량률을 과도하게 해석하지 않는가

### 6. 공정 변수 시계열 시각화

```text
불량 발생 시점을 표시하면서 주요 공정 변수의 시간별 변화를 시각화해줘.
```

추천 변수:

- `Max_Injection_Pressure`
- `Average_Back_Pressure`
- `Hopper_Temperature`
- `Cycle_Time`

확인 포인트:

- 라인 차트에 불량 발생 지점을 표시하는가
- 불량 직전/직후 변수 변화나 drift를 확인할 수 있는가
- 특정 변수의 급격한 변화와 불량 발생 시점의 관계를 보여주는가
- 제품 전환 또는 시간 구간 차이를 고려하는가

### 7. 온도 센서 시각화

```text
Barrel_Temperature와 Mold_Temperature 계열 센서 값을 비교 시각화해줘.
```

확인 포인트:

- 센서별 값 분포를 비교하는가
- 전부 0인 온도 센서를 구분하는가
- 실제 값이 있는 센서와 무의미한 센서를 구분하는가
- `Mold_Temperature_3`, `Mold_Temperature_4`처럼 실질적으로 값이 있는 컬럼을 별도로 해석하는가
- 온도 계열 컬럼을 모두 동일하게 유효 변수로 취급하지 않는가

### 8. 상관관계 시각화

```text
주요 수치형 공정 변수 간 상관관계를 히트맵으로 시각화해줘.
```

확인 포인트:

- 식별자 컬럼을 제외하는가
- 상수 컬럼이나 대부분 0인 컬럼을 제외하거나 별도 표시하는가
- 시간, 압력, 온도, 위치 변수 간 관계를 해석할 수 있게 보여주는가
- 너무 많은 컬럼을 한 번에 넣어 히트맵이 읽기 어려워지지 않는가

### 9. 이상치 시각화

```text
주요 공정 변수에서 이상치를 탐색할 수 있도록 시각화해줘.
```

확인 포인트:

- boxplot 또는 scatter plot을 사용하는가
- 압력, 시간, 온도 변수의 이상치를 확인하는가
- 이상치가 불량 데이터와 겹치는지 표시하는가
- 이상치를 무조건 불량 원인으로 단정하지 않는가

### 10. 데이터 품질 시각화

```text
결측값, 0값 비율, 상수 컬럼을 한눈에 볼 수 있도록 시각화해줘.
```

확인 포인트:

- 컬럼별 0값 비율 막대그래프를 생성하는가
- 상수 컬럼 목록을 제공하는가
- 분석에서 제외해야 할 컬럼을 표시하는가
- `Mold_Temperature` 계열의 무의미한 컬럼을 잡아내는가
- 데이터 품질 문제와 분석 결과 해석의 한계를 연결하는가

## 우선 테스트 질문 TOP 3

### TOP 1

```text
양품과 불량의 비율, 불량 사유별 건수, 제품별 생산량을 각각 적절한 그래프로 시각화해줘.
```

이 질문은 기본 분포, 범주형 변수 처리, 불량 클래스 불균형 인식을 한 번에 확인할 수 있다.

### TOP 2

```text
양품과 불량을 기준으로 주요 공정 변수의 분포를 비교 시각화해줘.
```

이 질문은 수치형 공정 변수 선택, 분포 비교 그래프 선택, 불량 표본 수 한계 인식을 확인하기 좋다.

### TOP 3

```text
시간 흐름에 따라 생산량과 불량 발생 추이를 시각화해줘.
```

이 질문은 `TimeStamp` 처리, 시계열 집계, 불량 발생 패턴 표현 능력을 확인하기 좋다.

## 시각화 결과 평가 체크리스트

- [ ] `PassOrFail`의 불균형을 시각적으로 보여준다.
- [ ] 불량 사유별 건수와 비율을 구분해서 보여준다.
- [ ] 제품별 비교에서 총 생산량과 불량률을 함께 고려한다.
- [ ] 식별자 컬럼을 수치 분석 변수로 사용하지 않는다.
- [ ] 전부 0이거나 대부분 0인 컬럼을 데이터 품질 이슈로 표시한다.
- [ ] 질문 목적에 맞는 그래프 유형을 선택한다.
- [ ] 그래프가 너무 복잡하지 않고 해석 가능한 수준으로 구성된다.
- [ ] 시각화 해석에서 원인을 단정하지 않고 관련 가능성으로 표현한다.

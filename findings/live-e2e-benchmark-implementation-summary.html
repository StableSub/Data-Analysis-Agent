Live 실행 구조

단계내용
환경.env 자동 로드, RUN_LIVE_BENCHMARK=1, OPENAI_API_KEY, langchain-openai 확인
DBlocal app.db 대신 temp SQLite DB에 benchmark Dataset row 등록
실행AgentClient.astream_with_trace(...)로 실제 workflow 호출
검증done event의 answer, output_type, evidence_package, answer_quality, analysis_result 검증

현재 환경에서 skip된 이유

  • langchain-openai package가 설치되어 있지 않음
  • BENCHMARK_SOURCE_ID_*는 선택 사항이며, 없으면 raw CSV 기준 source_id를 자동 생성함

실제 Live 실행 명령

PYTHONPATH=. pytest -q backend/tests/evaluation/live -m live_benchmark -s

필요한 env 예:

RUN_LIVE_BENCHMARK=1
OPENAI_API_KEY=...
# BENCHMARK_SOURCE_ID_MOLDSET_LABELED=...  # optional override
BENCHMARK_MODEL_ID=gpt-5-nano
BENCHMARK_LIVE_CASE_IDS=p0_moldset_label_distribution
BENCHMARK_LIVE_TIMEOUT_SECONDS=120
